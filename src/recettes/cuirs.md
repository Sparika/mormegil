# Cuirs

Recettes pour peindre les peaux et les cuirs ...


## Un cuir clair

Un cuir clair en utilisant la triade {{ paint:scabbard-brown }}

### Matériel nécessaire

- {{ paint:scabbard-brown }} (shade)
- {{ paint:boot-strap-brown }} (medium)
- {{ paint:vambrace-brown }} (highlight)
- {{ paint:battle-mud-wash }} (wash)

## Étapes

Étapes classiques de la peinture avec le système de triades, shade -> wash -> layer -> highlight.

1. **Base** : Appliquer {{ paint:scabbard-brown }}  en couche uniforme sur toute la zone de cuir.
2. **Lavis** : Appliquer {{ paint:battle-mud-wash }} en une couche.
3. **Layer** : Appliquer {{ paint:boot-strap-brown }} en sur les surfaces hautes en évitant les creux et les zones plus sombres.
4. **Détails** : Éclaircissement au {{ paint:vambrace-brown }} sur les arrêtes.


## Un cuir sale

Un cuir sombre en utilisant la triade {{ paint:druid-flesh }}.

### Matériel nécessaire

- {{ paint:druid-flesh }} (shade)
- {{ paint:paladin-flesh }} (medium)
- {{ paint:bard-skin }} (highlight)
- {{ paint:battle-mud-wash }} (wash)
- {{ paint:necrosis-green-wash }} (wash)

## Étapes

Étapes classiques de la peinture avec le système de triades, shade -> wash -> layer -> highlight.
On utilise un mélange de deux wash pour assombrir et salir le rendu.

1. **Base** : Appliquer {{ paint:druid-flesh }}  en couche uniforme sur toute la zone de cuir.
2. **Lavis** : Appliquer un mélange 1:1 {{ paint:battle-mud-wash }} {{ paint:necrosis-green-wash }} en une couche.
3. **Layer** : Appliquer {{ paint:paladin-flesh }} en sur les surfaces hautes en évitant les creux et les zones plus sombres.
4. **Détails** : Éclaircissement au {{ paint:bard-skin }} sur les arrêtes.
